This folder contains scripts to generate the data and scripts to produce figures from the accompanying manuscript. The only changes the reader needs to make is to appropriately modify "path/to/folders" where ever this appears in the scripts and needs to have the python packages installed in the environment they are running the scripts from.

As the lattice data itself is not public, we are providing trained models on the data which the reader can use to evaluate the models - but they will not be able to train the models for the lattice data.
